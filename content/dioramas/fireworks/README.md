# Fireworks on the lawn

Three staggered rockets burst into a fixed pool of 96 falling sparks. Forty spectators face the launch area and local lights pulse with the bursts.

This is an illustrative, deterministic performance, not a live event or operational simulation.
All geometry is generated by its ordinary Molen TypeScript scene script. Copy this directory
to reuse it; no external model or texture assets are required. The bounds describe local metres.
The host chooses the geographic placement, proximity and schedule.

Run `molen sim run scene.json --ticks 720 --hash` or `molen shot scene.json --ticks 210 --out shot.png`
from this directory. Generated script declarations are checked with `molen scripts check` from
the parent content project. Motion is tick-derived and checkpoint-safe; entity pools stay fixed.
