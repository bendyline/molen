# U.S. reference vehicles

Forty representative vehicles from the U.S. market, emphasizing familiar high-volume models while including Prius, Model 3 and Mustang. This is a curated selection, not a strict top-40 sales ranking. The existing Bendy vehicles remain available.

All forty are drivable through Molen's vehicle/mount API. Each has an editable source bundle, deterministic GLB generator, imported runtime sidecar, named wheel/steering pivots, a cabin, an entry and exits. No bitmap textures or downloaded meshes are used.

These are stylized polygonal reference interpretations. Body envelopes and wheelbases are rounded authoring targets; trim details and cockpit graphics are simplified. Handling parameters are gameplay tuning, not certified performance data. The dashboard map/status graphics are illustrative; analog speed needles are bound where present, and the host driving HUD provides live telemetry. Manufacturer, model and year names identify what each interpretation depicts; the geometry carries no maker emblem, wordmark, model lettering or logo-shaped grille — a plain chrome badge and a fictional `MLN` plate stand in. See [NOTICE.md](NOTICE.md).

The showroom is [scenes/us-vehicles.scene.json](scenes/us-vehicles.scene.json). The full ID prefix is `molen.entities.vehicle.`. Both `MOLEN_US_VEHICLE_ENTITY_IDS` and the general `MOLEN_VEHICLE_ENTITY_IDS` expose these types.

## Authoring and validation

Example targeted rebuild:

```sh
node packages/entities/scripts/generate-fleet.mjs --ids=ford-f-150-2025,toyota-prius-2024,tesla-model-3-2025
node packages/tooling/dist/cli.mjs asset import content/entities/source/vehicles/ford-f-150-2025/models/source.glb --id molen.entities.vehicle.ford_f_150_2025 --project content/entities/project.json --force
node packages/entities/scripts/generate-models.mjs
node packages/entities/scripts/capture-fleet.mjs --ids=ford-f-150-2025
```

The shared generator is [road-vehicle-geometry.mjs](../../packages/entities/scripts/road-vehicle-geometry.mjs). The asset build's existing `entities-fleet` job discovers these recipes automatically. Source masters are protected against overwriting artist edits. Source and imported hashes, geometry budgets, interior bindings and boarding/driving/braking/reversing/exiting are checked by the entity tests.

See [US-VEHICLE-REVIEW.md](US-VEHICLE-REVIEW.md) for the reviewed batch and limitations. Bulk review captures stay in ignored per-model `shots/` folders.
