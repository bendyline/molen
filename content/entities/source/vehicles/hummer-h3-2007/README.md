# 2007 Hummer H3

![Molen preview](preview.png)

Base SUV; offroad. Original polygonal reference interpretation for close-view driving.

Rounded authoring envelope: 4.49 × 1.897 × 1.872 m, excluding mirrors and rear spare; wheelbase 2.842 m. Geometry includes actual wheel openings, hollow cabin, seats, controls, mirrors, wipers, lamps and separate wheel/caliper transforms. Model-specific proportions and features are editable in models/recipe.json.

[Reference context](https://files.directechs.com/directwirebrochures/brochure2262_0.pdf) — manufacturer material, including archived brochures where necessary. Sources establish generation/design context; not every authored dimension or trim detail is independently measured. No downloaded geometry or bitmap textures. Dashboard graphics and handling are simplified for play. 

Generate: node packages/entities/scripts/generate-fleet.mjs --ids=hummer-h3-2007. Import the resulting GLB using the source manifest ID. Capture: node packages/entities/scripts/capture-fleet.mjs --ids=hummer-h3-2007. The shared generator is packages/entities/scripts/road-vehicle-geometry.mjs.
