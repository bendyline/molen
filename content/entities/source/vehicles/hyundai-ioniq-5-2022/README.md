# 2022 Hyundai IONIQ 5

![Molen preview](preview.png)

SEL battery electric; hatchback. Original polygonal reference interpretation for close-view driving.

Rounded authoring envelope: 4.635 × 1.89 × 1.605 m, excluding mirrors and rear spare; wheelbase 3 m. Geometry includes actual wheel openings, hollow cabin, seats, controls, mirrors, wipers, lamps and separate wheel/caliper transforms. Model-specific proportions and features are editable in models/recipe.json.

[Reference context](https://www.hyundainews.com/releases/3631?lang=es_MX) — manufacturer material, including archived brochures where necessary. Sources establish generation/design context; not every authored dimension or trim detail is independently measured. No downloaded geometry or bitmap textures. Dashboard graphics and handling are simplified for play. 

Generate: node packages/entities/scripts/generate-fleet.mjs --ids=hyundai-ioniq-5-2022. Import the resulting GLB using the source manifest ID. Capture: node packages/entities/scripts/capture-fleet.mjs --ids=hyundai-ioniq-5-2022. The shared generator is packages/entities/scripts/road-vehicle-geometry.mjs. Bulk renders stay in ignored shots/; see content/entities/VARIETY-VEHICLE-REVIEW.md for batch evidence.
