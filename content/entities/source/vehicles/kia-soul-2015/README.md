# 2015 Kia Soul

![Molen preview](preview.png)

Plus five-door; hatchback. Original polygonal reference interpretation for close-view driving.

Rounded authoring envelope: 4.14 × 1.8 × 1.6 m, excluding mirrors and rear spare; wheelbase 2.57 m. Geometry includes actual wheel openings, hollow cabin, seats, controls, mirrors, wipers, lamps and separate wheel/caliper transforms. Model-specific proportions and features are editable in models/recipe.json.

[Reference context](https://www.kiamedia.com/us/en/models/soul/2015/specifications) — manufacturer material, including archived brochures where necessary. Sources establish generation/design context; not every authored dimension or trim detail is independently measured. No downloaded geometry or bitmap textures. Dashboard graphics and handling are simplified for play. 

Generate: node packages/entities/scripts/generate-fleet.mjs --ids=kia-soul-2015. Import the resulting GLB using the source manifest ID. Capture: node packages/entities/scripts/capture-fleet.mjs --ids=kia-soul-2015. The shared generator is packages/entities/scripts/road-vehicle-geometry.mjs.
