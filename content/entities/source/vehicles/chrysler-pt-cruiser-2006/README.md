# 2006 Chrysler PT Cruiser

![Molen preview](preview.png)

Touring five-door; hatchback. Original polygonal reference interpretation for close-view driving.

Rounded authoring envelope: 4.29 × 1.705 × 1.601 m, excluding mirrors and rear spare; wheelbase 2.616 m. Geometry includes actual wheel openings, hollow cabin, seats, controls, mirrors, wipers, lamps and separate wheel/caliper transforms. Model-specific proportions and features are editable in models/recipe.json.
