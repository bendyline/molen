# 2006 Scion xB

![Molen preview](preview.png)

First generation five-door; hatchback. Original polygonal reference interpretation for close-view driving.

Rounded authoring envelope: 3.945 × 1.69 × 1.64 m, excluding mirrors and rear spare; wheelbase 2.5 m. Geometry includes actual wheel openings, hollow cabin, seats, controls, mirrors, wipers, lamps and separate wheel/caliper transforms. Model-specific proportions and features are editable in models/recipe.json.

[Reference context](https://pressroom.toyota.com/scion-fact-sheet/) — manufacturer material, including archived brochures where necessary. Sources establish generation/design context; not every authored dimension or trim detail is independently measured. No downloaded geometry or bitmap textures. Dashboard graphics and handling are simplified for play. 

Generate: node packages/entities/scripts/generate-fleet.mjs --ids=scion-xb-2006. Import the resulting GLB using the source manifest ID. Capture: node packages/entities/scripts/capture-fleet.mjs --ids=scion-xb-2006. The shared generator is packages/entities/scripts/road-vehicle-geometry.mjs. Bulk renders stay in ignored shots/; see content/entities/VARIETY-VEHICLE-REVIEW.md for batch evidence.
