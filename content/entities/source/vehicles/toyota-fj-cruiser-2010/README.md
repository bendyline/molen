# 2010 Toyota FJ Cruiser

![Molen preview](preview.png)

4x4, white roof; offroad. Original polygonal reference interpretation for close-view driving.

Rounded authoring envelope: 4.44 × 1.905 × 1.829 m, excluding mirrors and rear spare; wheelbase 2.69 m. Geometry includes actual wheel openings, hollow cabin, seats, controls, mirrors, wipers, lamps and separate wheel/caliper transforms. Model-specific proportions and features are editable in models/recipe.json.

[Reference context](https://pressroom.toyota.com/presskit/toyota-fj-cruiser-2010/) — manufacturer material, including archived brochures where necessary. Sources establish generation/design context; not every authored dimension or trim detail is independently measured. No downloaded geometry or bitmap textures. Dashboard graphics and handling are simplified for play. 

Generate: node packages/entities/scripts/generate-fleet.mjs --ids=toyota-fj-cruiser-2010. Import the resulting GLB using the source manifest ID. Capture: node packages/entities/scripts/capture-fleet.mjs --ids=toyota-fj-cruiser-2010. The shared generator is packages/entities/scripts/road-vehicle-geometry.mjs. Bulk renders stay in ignored shots/; see content/entities/VARIETY-VEHICLE-REVIEW.md for batch evidence.
