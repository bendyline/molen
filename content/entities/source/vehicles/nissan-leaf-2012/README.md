# 2012 Nissan Leaf

![Molen preview](preview.png)

SL, first generation; hatchback. Original polygonal reference interpretation for close-view driving.

Rounded authoring envelope: 4.445 × 1.77 × 1.55 m, excluding mirrors and rear spare; wheelbase 2.7 m. Geometry includes actual wheel openings, hollow cabin, seats, controls, mirrors, wipers, lamps and separate wheel/caliper transforms. Model-specific proportions and features are editable in models/recipe.json.

[Reference context](https://usa.nissannews.com/en-US/releases/nissan-to-launch-all-electric-leaf-as-upgraded-2012-model-in-new-u-s-markets) — manufacturer material, including archived brochures where necessary. Sources establish generation/design context; not every authored dimension or trim detail is independently measured. No downloaded geometry or bitmap textures. Dashboard graphics and handling are simplified for play. 

Generate: node packages/entities/scripts/generate-fleet.mjs --ids=nissan-leaf-2012. Import the resulting GLB using the source manifest ID. Capture: node packages/entities/scripts/capture-fleet.mjs --ids=nissan-leaf-2012. The shared generator is packages/entities/scripts/road-vehicle-geometry.mjs.
