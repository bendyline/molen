Touring coupe; coupe. Original polygonal reference interpretation for close-view driving.

Rounded authoring envelope: 4.245 × 1.845 × 1.315 m, excluding mirrors and rear spare; wheelbase 2.55 m. Geometry includes actual wheel openings, hollow cabin, seats, controls, mirrors, wipers, lamps and separate wheel/caliper transforms. Model-specific proportions and features are editable in models/recipe.json.
