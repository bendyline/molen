# 2005 Ford GT

![Molen preview](preview.png)

First generation coupe; coupe. Original polygonal reference interpretation for close-view driving.

Rounded authoring envelope: 4.643 × 1.953 × 1.125 m, excluding mirrors and rear spare; wheelbase 2.71 m. Geometry includes actual wheel openings, hollow cabin, seats, controls, mirrors, wipers, lamps and separate wheel/caliper transforms. Model-specific proportions and features are editable in models/recipe.json.

[Reference context](https://media.ford.com/content/fordmedia/feu/nl/nl/news/2017/05/12/racing-to-the-future--how-ford-created-the-gt-supercar-to-test-t.html) — manufacturer material, including archived brochures where necessary. Sources establish generation/design context; not every authored dimension or trim detail is independently measured. No downloaded geometry or bitmap textures. Dashboard graphics and handling are simplified for play.
