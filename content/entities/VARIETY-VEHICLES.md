# Vehicle variety: 2005–2024

Forty more real vehicle identities, selected for variety across brands, sizes and body shapes. There are two models from each year in the requested interval. This is an eclectic curated collection, not a sales ranking or a statistical random sample. The earlier forty recent vehicles and the Bendy collection remain available.

All forty are mountable and drivable, with named steering and wheel pivots, fixed brake calipers, close-view interiors, entry/exit points and ambient car roles. Open-top roadsters, compact city cars, wagons, cargo vans, retro hatchbacks, coupes, sedans, pickups and off-road models give the collection a wider silhouette range. The models use original polygonal geometry and flat material colors, with no bitmap textures or downloaded meshes.

These are stylized reference interpretations. Authoring dimensions are rounded; badges, trim, interior layouts and drivetrain behavior are simplified. Period-style radios and analog dials replace tablet screens in older cabins. Analog speed needles and steering animate; screen graphics are illustrative and live telemetry comes from the host HUD. Doors, convertible roofs, cargo doors and pickup tailgates do not animate. Open-top models have fixed lowered roofs. Manufacturer, model and year names identify what each interpretation depicts; the geometry carries no maker emblem, wordmark, model lettering or logo-shaped grille — a plain chrome badge and a fictional `MLN` plate stand in. See [NOTICE.md](NOTICE.md).

The full ID prefix is `molen.entities.vehicle.`. `MOLEN_VARIETY_VEHICLE_ENTITY_IDS` exports this collection; its IDs are also in `MOLEN_VEHICLE_ENTITY_IDS` and `MOLEN_ENTITY_IDS`. The repository showroom is [scenes/variety-vehicles.scene.json](scenes/variety-vehicles.scene.json).

## Authoring

Each bundle contains editable proportions/features in `models/recipe.json`, its type definition, source manifest and reference links. References provide generation/design context; they are not a claim that every authored measurement matches factory data. The shared generator [road-vehicle-geometry.mjs](../../packages/entities/scripts/road-vehicle-geometry.mjs) preserves the previous collection by enabling new body features only through recipe options. The existing `entities-fleet` asset-build job discovers these sources automatically.

```sh
node packages/entities/scripts/generate-fleet.mjs --ids=mazda-mx-5-miata-2016
node packages/tooling/dist/cli.mjs asset import content/entities/source/vehicles/mazda-mx-5-miata-2016/models/source.glb --id molen.entities.vehicle.mazda_mx_5_miata_2016 --project content/entities/project.json --force
node packages/entities/scripts/generate-models.mjs
node packages/entities/scripts/capture-fleet.mjs --ids=mazda-mx-5-miata-2016
```

See [VARIETY-VEHICLE-REVIEW.md](VARIETY-VEHICLE-REVIEW.md) for checks, budgets and render evidence. Near-view masters use host distance/proxy policies rather than a separate authored GLB LOD chain. Bulk renders remain in ignored per-model `shots/` folders.
