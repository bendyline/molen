# Coastal source-ground candidates

Original public DeltaDTM v1.1.1, dataset release4, CC BY4.0:
https://doi.org/10.4121/21997565 . Provider README, attribution and
full method details are retained in the completed White Tower and
Hotel Majapahit terrain-sources bundles. One arcsecond source spacing
is approximately30m; it does not establish surveyed floor accuracy.

These original HTTP byte ranges and diagnostic records are retained
for rejected Mumbai and Cadmans Cottage candidates. Original fields,
model geometry,frames and dry references remain unchanged. Mumbai dry
references hit NODATA;no interpolation across missing pixels is used.
Cadmans rear entry remains incompatible with the candidate field.
No completed-story associations are exported for these held models.
The complete archive/TIFF CRC is not claimed for retained subsets.
