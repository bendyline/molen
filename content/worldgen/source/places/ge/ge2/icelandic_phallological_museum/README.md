# Icelandic Phallological Museum

The Icelandic Phallological Museum occupies the Hafnartorg corner with its recessed glass entrance, two projecting museum signs and stone threshold sculpture. The shared retail and office block rises in stepped terraces with deep concrete window surrounds and rooftop equipment.

Run `node packages/worldgen/scripts/generate-hafnartorg-museum.mjs` to rebuild the source master. The landmark LOD generator exports four detail levels with shared concrete, painted metal and granite.

OpenStreetMap via Protomaps supplies the museum point, the occupied block and the street alignment. The viewer uses the host terrain at the museum point. The model replaces only the occupied Kalkofnsvegur 2 footprint.
