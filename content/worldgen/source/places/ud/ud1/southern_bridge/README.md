# Southern Bridge (Dienvidu tilts)

Six orange extradosed pylons carry the twin steel box girders across the Daugava. The 803 m crossing includes eight pairs of stays per pylon, six traffic lanes, two sidewalks, eight reinforced concrete piers and two abutments. The four authored detail levels use three shared material graphs.

Run `node packages/worldgen/scripts/generate-southern-bridge.mjs` to rebuild the detailed master. The landmark LOD generator exports the runtime levels.

OpenStreetMap via Protomaps PMTiles supplies the signed placement and four connection traces. The published bridge load-testing paper supplies the span sequence, width, pylon height and stay count. Exterior photos and standard Terrarium support the estimated deck profile and foundations. The nearby elevated continuation and the path below the southwest approach are retained as mapped viewer features.
