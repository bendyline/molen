# India Gate aerial silhouette

Brief: a small medium-fi landmark replacing the generic building in the Central Vista comparison.
42 m tall, open semicircular passage, sandstone piers, red plinth, stepped cornice and shallow bowl.
Other dimensions are photographic estimates, not surveyed measurements. No inscriptions or unique textures.

Height and principal form: [Delhi Tourism](https://www.delhitourism.gov.in/tourist_place/india_gate.html).
Visual reference: the credited CC BY 3.0 Central Vista photograph in the World Explorer
[aerial reference manifest](../../../../../../../examples/world-explorer/aerial-comparison.reference.json).
This is an original procedural reconstruction; no photographic pixels are embedded.

Rebuild: `node packages/worldgen/scripts/generate-india-gate.mjs`.
Import through the registered worldgen project, then inspect and render with the Molen CLI.
The normal generated source and runtime GLBs remain ignored build outputs.
