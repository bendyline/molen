# Altenmünster at Lorsch

Low, irregular stone walls mark the former church, with three open thresholds, a narrower eastern chamber and surrounding grass-covered earthworks. The model represents the visible display foundations.

Run `node packages/worldgen/scripts/generate-lorsch-abbey.mjs --ids=altenmunster_lorsch` to rebuild the source master. The landmark LOD generator exports four runtime levels. This is an independently placed member of the Abbey and Altenmünster of Lorsch.

OpenStreetMap via Protomaps supplies the mapped site controls. Standard Terrarium elevations set the 97.22 m datum. PMTiles locates the archaeological site and its meadow. The wall outlines and facing are photo-based estimates within that mapped setting. The mesh represents the visible modern display foundations and earthworks. The former monastery remains represented by its surviving ground traces.
