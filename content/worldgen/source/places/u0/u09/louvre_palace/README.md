# Louvre Palace

The source rebuilds the palace ranges, limestone pavilions, open Cour Carrée, museum skylights, and the Cour Napoléon pyramid group. The Arc de Triomphe du Carrousel, surrounding streets and Seine remain separate map features.

Rebuild the source with `node packages/worldgen/scripts/generate-louvre-palace.mjs`. The model uses existing limestone, slate, painted metal and glazing surfaces.

The exterior interprets sculptural details and the pyramid glass using shared materials. The standard terrain surface obscures portions of the lowest façade band in Cour Carrée.
