# Odinstårnet

The two square steel frames step inward at the star-shaped restaurant. Open X bracing surrounds the lift, and the upper deck carries the conch-stair pavilion and its thin mast. Reinforced-concrete footings and an open roadside dining terrace anchor the tower.

Run `node packages/worldgen/scripts/generate-odinstarnet.mjs` to regenerate the detailed source GLB. The four authored runtime levels share painted steel, concrete, lime plaster and standing-seam metal.

Set the historical date to 1938-06-01 in the viewer. The signed layout places the tower on the memorial at Bolbro Bakke, with its roadside entrance toward Middelfartvej. The terrain and surrounding neighborhood use current data.
