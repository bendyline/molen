# Frankish Tower

The reconstructed Frankish Tower has the measured 8.69 by 7.78 m plan, weathered masonry courses with reused Pentelic blocks, the east window, a north projection, timber access stair and uneven crenellations above the southwest wing of the Propylaia.

Run `node packages/worldgen/scripts/generate-frankish-tower.mjs` to regenerate the detailed source GLB. The four authored runtime levels reuse weathered limestone, quarried limestone, marble and wood.

Set the historical date to 1869-06-01 in the viewer. The historic tower adjoins the south wing of the Propylaia. The surrounding Acropolis and terrain use current map data.
