# Golestan Palace

Golestan Palace before the March 2026 damage, with the twin towers and clock of Shams-ol Emareh, the blue tiled windcatchers, the Marble Throne terrace, the main halls and the interconnected garden pools.

This dated reconstruction represents the palace before the damage reported on 2 March 2026. The native buildings remain visible with the viewer set to the present.
