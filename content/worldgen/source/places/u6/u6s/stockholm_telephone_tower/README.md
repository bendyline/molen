# Stockholm Telephone Tower

The Brunkeberg exchange has three gabled bays at each street front and a standing-seam roof. The 1890s telephone tower has an open iron lattice, horizontal insulator rows, rosette railings and four corner crowns with tall spindles.

Run `node packages/worldgen/scripts/generate-stockholm-telephone-tower.mjs` to rebuild the detailed master. The landmark LOD generator exports four levels using common Flemish brick, sandstone, painted iron and standing-seam metal materials.

Set the viewer’s historical date to 1895-06-01 to see the original exchange and the decorated tower. The model fits the measured Åskslaget 14 lot plan to the municipal archive’s position and the mapped street axis. Surrounding modern streets and buildings come from Protomaps.
