# Charing Cross

The Whitehall-facing dark bronze shows Charles I in armor with curled hair, reins, boots and a sword. The horse raises one foreleg above the molded Portland stone pedestal with carved heraldry and supporters.

Run `node packages/worldgen/scripts/generate-charing-cross-monument.mjs` to rebuild the source master. The landmark LOD generator exports four detail levels with shared cast bronze, limestone and granite.

The Charles I point, pedestal outline, pedestrian island and Whitehall alignment come from OpenStreetMap via Protomaps. The model replaces only the procedural pedestal. The figure and the carved relief use exterior photographs. The ground is sampled from standard Terrarium tiles.
