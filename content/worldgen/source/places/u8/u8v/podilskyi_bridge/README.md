# Podilskyi Bridge

Two gently inclined steel arch ribs rise 66.1 meters over the double deck. Cable hangers suspend the six-lane upper roadway, while deep trusses carry the lower metro deck. Paired concrete bearings and two 64 meter side spans connect to the mapped approach viaducts.

Run `node packages/worldgen/scripts/generate-podilskyi-bridge.mjs` to rebuild the detailed master. The landmark LOD generator exports four levels. Shared board-formed concrete, deck concrete and painted steel use metric UVs.

The 472 meter main river bridge follows the two PMTiles carriageways. Its 344 meter arch, lower deck and approach spans use the published engineering elevation and aerial views. The model hands off to the existing viaducts at both ends.
