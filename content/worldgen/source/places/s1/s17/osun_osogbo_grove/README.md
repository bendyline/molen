# Ọ̀ṣun–Òṣogbo Sacred Grove

The structure catalog groups the grove's individual buildings, gateways and sculptures as a
collection. Each model has an independent source, GLB, review, and placement record where the
geographic evidence supports one. The renderer uses the native terrain, forest and River Osun
for the landscape.
