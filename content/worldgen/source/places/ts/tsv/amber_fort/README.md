# Amber Fort

Amber Fort’s sandstone palace above Maota Lake, with Jaleb Chowk, the public audience hall, Ganesh Pol, the Charbagh court, Sheesh Mahal and the Man Singh Mahal court.

The four stepped courts, sandstone masses and pale marble halls stand on the mapped Amber Fort outline above Maota Lake.

Run the Amber Fort generator registered in asset-build.json to rebuild the detailed source. The four detail levels use shared sandstone, marble, patterned tile, plaster, stone screen and paving. The exterior paint patterns and carving are interpreted from photographs.
