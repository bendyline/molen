# Sintra terrain source evidence

The DGT public mainland LiDAR viewer exposes classified compressed point data without a login. The retained response ranges and two indexes cover the palace and its surrounding ground. They are the original public viewer responses, **not complete unmodified survey LAZ files**. The source filenames identify July 2024; the viewer headers give a February 2026 re-encoding date. Attribution: Direção-Geral do Território (DGT), mainland Portugal LiDAR 2024–2025, [CC BY 4.0](https://www.dgterritorio.gov.pt/dados-abertos).

`public-range-manifest.json` records every URL, requested byte range, response length, SHA256 and chunk identifier. Ten compressed responses contain 127 chunks and 36,352,402 bytes. Original response headers and both provider indexes are retained. The original public JavaScript/WASM decoder was inspected and used locally; its source URLs/hashes are recorded, and its code is not redistributed here.

`dgt-class2-ground.xyz-f32le.gz` contains the 911,745 decoded ground points, little-endian Float32 E/N/H triples in PT-TM06/ETRS89 (EPSG:3763), with Cascais heights per DGT documentation. Heights were not altered. Class 6 roof, wall and raised-court returns are excluded from terrain; separate structural observations are saved in the parent folder. No exact original survey precision or flight day is certified.

The 125 by 125 review grid uses a fixed 12-neighbor inverse squared distance rule, chosen before model geometry. Equal-distance candidates sort by original point index. Most covered palace areas have no classified ground returns: the largest distance to the nearest support point is 22.123 m. Interpolated ground underneath buildings is uncertain and retaining steps can be smoothed. No surface was fitted or flattened to match a model. The dry southeast forecourt reference is local [-6,38], with a 210.5518 m datum and a classified ground return 0.125 m away. Compatible host terrain is required; default Earth terrain is not certified.

Run `python3 verify-derived-grid.py` from any directory, with NumPy available. It checks all 15,625 height and support values, the decoded ground hash, and the retained provider response/index hashes without changing files or reading model geometry. Separate independent full-cloud nearest-neighbor checks at 122 locations also passed. See the parent `terrain-source-review.json` for provenance and limits.
