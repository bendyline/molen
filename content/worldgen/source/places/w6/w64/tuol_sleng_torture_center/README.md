# Tuol Sleng Genocide Museum

The four former school buildings and central annex sit within the memorial campus on Street 113 in Phnom Penh. The model includes open galleries, the wire screen on Building C, the north memorial and name steles, the south cemetery, paths and planting. It uses six shared material graphs and authored vertex colors for vegetation.

Run `node packages/worldgen/scripts/generate-tuol-sleng-museum.mjs` to rebuild the source master. The landmark LOD generator exports the four authored runtime levels.

The Protomaps PMTiles features fix the five occupied footprints and the signed orientation. The standard Terrarium grid sets the terrain datum and path grades. Facade dimensions and courtyard planting are estimates from published exterior photos. The model depicts the exterior, including the memorials, with unlettered steles.
