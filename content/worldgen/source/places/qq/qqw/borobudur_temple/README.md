# Borobudur Temple

Six stepped square terraces and four stairways rise to three circular terraces carrying 72 smaller pierced stupas and the solid central stupa. Shared basalt masonry and raw basalt tinted to weathered andesite. [Reference observations](reference-observations.json)

The registered generator in `asset-build.json` rebuilds the source GLB, and the same recipe exports four authored runtime levels. [Site controls](site-controls.json)
