# Sheikh Jaber al-Ahmad al-Sabah Causeway

The assembly combines the Main Link, its cable-stayed navigation span, the Doha Link, and the directly connected elevated ramps. Fifty sections stream independently. The source uses shared concrete and painted metal materials.

Run `node packages/worldgen/scripts/generate-sheikh-jaber-causeway.mjs` to rebuild the detailed source. The runtime LOD generator exports each section's four authored levels.

Plan and orientation follow OpenStreetMap via Protomaps PMTiles. Deck grades, span heights, pier locations and ramp transitions are visual estimates based on Terrarium and reference photos. Native ground roads and independent interchange links remain in the viewer.
