# Al-Ayn Beehive Tombs

Twenty individually mapped beehive tombs climb the rocky ridge. The weathered dry-stone shells vary in height and taper, with stepped corbelled tops, open lintelled entries and lower collapsed remains. [Reference observations](reference-observations.json)

The source generator rebuilds the master GLB. Four authored detail levels use the shared material library. [Site controls](site-controls.json)
