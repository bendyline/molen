# Summer Palace · West Gate and canal crossing

The modern west-facing gatehouse, bronze lions, low checkpoint shelter and broad balustraded bridge follow visitor photographs. The gate is fitted to the mapped approaches and overhead imagery. The ticket buildings use their PMTiles footprints. The model uses an estimated bridge section, exterior proportions, gate alignments and carving.

Rebuild this model with `node packages/worldgen/scripts/generate-summer-palace.mjs --ids=summer_palace_west_gate`.
