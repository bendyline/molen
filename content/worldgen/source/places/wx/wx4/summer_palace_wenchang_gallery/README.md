# Summer Palace · Wenchang Gallery

The museum uses the mapped courtyard ring and separate exhibition rooms. The visitor gate and tiled galleries are reconstructed from photographs. The position of the gate within the range, the inner paths and decorative details are approximate. Interiors are omitted.

Rebuild this model with `node packages/worldgen/scripts/generate-summer-palace.mjs --ids=summer_palace_wenchang_gallery`.
