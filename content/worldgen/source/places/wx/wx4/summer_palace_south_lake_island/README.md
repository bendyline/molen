# Summer Palace · South Lake Island temples

Hanxu Hall uses its mapped T-shaped outline and a reconstructed north-facing rockery terrace and stairs. The Dragon King Temple uses its gold-tiled roof and south-facing court. Native island shores, paths and adjacent bridge remain as separate map geometry.
