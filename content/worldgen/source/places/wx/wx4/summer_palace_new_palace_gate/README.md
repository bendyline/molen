# Summer Palace · New Palace Gate

The photographed grey-tiled gatehouse is modeled at the transition to the mapped east-dyke footway. The placement is estimated from its approach with no native gate footprint to replace. Stone wings, modern checkpoint glazing and the central accessible passage follow the exterior photo. Native roads and footprints remain in place.

Rebuild this model with `node packages/worldgen/scripts/generate-summer-palace.mjs --ids=summer_palace_new_palace_gate`.
