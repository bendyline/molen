# Summer Palace · North Palace Gate

The two-storey North Palace Gate and two flanking ranges use the mapped footprints beside the Suzhou Street approach. The stone steps and balcony are reconstructed from photographs and the standard terrain. Modern turnstiles and upper-room interiors are omitted.

Rebuild this model with `node packages/worldgen/scripts/generate-summer-palace.mjs --ids=summer_palace_north_palace_gate`.
