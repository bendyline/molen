# Mukden Palace

The east court places the double-eaved octagonal Dazheng Hall between opposing rows of ten Banner Pavilions. The central axis runs from Daqing Gate and Chongzheng Hall to the raised Phoenix Tower passage. The western court includes the dark-tiled Wensu Library and the open theater courtyard.

Run `node packages/worldgen/scripts/generate-mukden-palace.mjs` to rebuild the source master. The landmark LOD generator exports four detail levels. They use shared timber, glazed and flat roof tile, brick, granite, plaster and bronze graphs.

OpenStreetMap via Protomaps supplies the footprint alignment for 62 historic roofs and building parts. Standard Terrarium elevations set the 54 m datum and the approaches. Smaller ancillary halls and the platform heights are approximate exterior reconstructions.
