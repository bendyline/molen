# Hwaseong Fortress

Hwaseong Fortress at Suwon. Four individually oriented gates, the seven arches of Hwahongmun, two distinct Gongsimdon watchtowers, five rampart reaches and the historic command pavilions.

The four principal defenses, seven-arch Hwahongmun, watchtowers and five modeled rampart reaches follow the city’s mapped features. Native hills and waterways remain.

Run the Hwaseong Fortress generator registered in asset-build.json to rebuild the detailed source. The four detail levels use shared granite, ashlar, brick, plaster, timber, painted trim, roof tile and gravel. The exterior paint patterns and sculpture are interpreted from photographs.
