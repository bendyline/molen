# Mansu Hill Grand Monument

The bronze pair and stone bases follow the PMTiles sculpture points. Both flanking groups include a sculpted bronze procession below the carved granite banners. The Korean Revolution Museum backdrop follows the three mapped building parts and depicts the mountain mural with colored geometry.

Run `node packages/worldgen/scripts/generate-mansu-hill-monument.mjs` to rebuild the source master. The landmark LOD generator exports four levels. The model uses the shared bronze, granite and marble material graphs.

OpenStreetMap via Protomaps PMTiles supplies the mapped plan. Standard Terrarium elevations set the 58 m datum and surrounding grades. The source records the exterior photographs and estimates used for the sculptural details.
