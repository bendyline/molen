# Arch of Reunification

Two granite women lean across the Pyongyang–Kaesong Highway and raise a circular bronze peninsula emblem. The broad folded garments abut the stone plinths and bronze relief panels on the plazas at either side of the roadway.

Run `node packages/worldgen/scripts/generate-arch-of-reunification.mjs` to regenerate the detailed source GLB. The four authored runtime levels share granite, rough stone, bronze and paved stone materials.

Set the historical date to 2016-06-01 in the viewer. The historic arch crosses the mapped Pyongyang–Kaesong Highway. The two plinths use the pre-demolition plaza footprint. The surrounding terrain and roads use modern data.
