# Georgia Guidestones

Four full-size rock-pitched granite wings surround the central gnomon. A cardinal capstone, separate explanatory tablet, inscribed faces, a solar slot and two open bores reproduce the standing monument.

Run `node packages/worldgen/scripts/generate-georgia-guidestones.mjs` to regenerate the detailed source GLB. The four authored runtime levels share granite and gravel materials.

Set the historical date to 2021-06-01 in the viewer. The historical reconstruction uses the pre-demolition monument pad between the west tablet and the former gravel access. The surrounding terrain and roads use current map data.
