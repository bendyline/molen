# Wadi Araba Crossing

The Rabin terminal has a long cream passenger hall, red steel inspection canopies and a white entry fascia. Across the paved crossing, Jordan’s two sculpted arches with a gold crown stand before blue-roofed checkpoint halls.

Build the master with the Wadi Araba generator registered in asset-build.json. The source recipe also exports the four viewer detail levels. Six shared graphs cover lime plaster, concrete, corrugated roofs, painted frames, the perforated fence and paving.

The gate and passenger halls use the mapped footprints. The original mapped roadway remains visible between the stone gate islands and exterior fences.
