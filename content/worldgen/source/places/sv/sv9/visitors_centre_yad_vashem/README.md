# Visitors Centre, Yad Vashem

![Molen preview](preview.png)

The square Visitors Centre retains its six-bay pale concrete frame, deep colonnades, recessed glazing, offset car-park entry, gridded roof and south terrace. The fitted deck exposes all four arcades and keeps the parking approach connected.
