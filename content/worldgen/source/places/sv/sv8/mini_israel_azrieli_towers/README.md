# Mini Israel · Azrieli Towers exhibit

This is the miniature display at Latrun. It includes the round, triangular and square towers at approximately 1:25 scale, their shopping podium, the model railway and the visitor-facing landscape shown in exhibit photographs. The tower façades use the shared window grid at a scale appropriate for the tabletop buildings. The model uses six shared material graphs. [Daylight exhibit photo](https://www.israel-in-photos.com/mini-israel.html) · [Evening exhibit photo](https://www.kikar.co.il/487/240739)

The 2022 drone footage fixes the approximate pad between the pool path and circular visitor plaza. The square tower is to the northeast of the triangular tower, with the model railway on the visitor-facing southeast side. The Earth viewer places the exhibit beside the mapped path using a small terrain grade that supports the deck. [Placement controls](map-frame.json) · [Drone footage](https://www.youtube.com/watch?v=7Zerh5_QLVA&t=82s)
