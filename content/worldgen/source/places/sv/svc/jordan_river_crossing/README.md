# Jordan River Crossing

The northern Jordan River Crossing has two parallel prestressed concrete decks with separate roadbeds, cast piers, chamfered girders and steel parapets. The model fits the mapped bend and joins both terminals’ approach lanes.

Run `node packages/worldgen/scripts/generate-jordan-river-crossing.mjs` to rebuild the detailed master. The landmark LOD generator exports four levels. Shared board-formed concrete, deck concrete and painted steel use metric UVs.

The two carriageways follow independent PMTiles bridge lines. The generated deck profiles connect to native approaches, with standard Terrarium providing the surrounding grades.
