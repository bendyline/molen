# Leaning Tower of Pisa

The south-leaning marble campanile has a broad blind-arcaded base, six open loggias and a narrower arcaded belfry. Shared marble, coursed stone, painted metal, cast bronze and timber. [Reference observations](reference-observations.json)

The registered generator in `asset-build.json` rebuilds the source GLB, and the same recipe exports four authored runtime levels. [Site controls](site-controls.json)
