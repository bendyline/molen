# Kharkiv Metro Bridge

The covered viaduct follows both tracks of the Saltivska line. Its corrugated roof, scalloped side skirt, recessed panels, concrete girders and portals use four shared material graphs across all detail levels.

Run `node packages/worldgen/scripts/generate-kharkiv-metro-bridge.mjs` to rebuild the detailed master. The standard landmark LOD generator exports the four authored runtime levels.

Both rail alignments follow OpenStreetMap via Protomaps PMTiles. The roof ends follow aerial imagery. Deck grades, bay spacing and individual support and portal dimensions are visual estimates based on the sampled terrain and exterior photos.
