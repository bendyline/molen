# Chongar railway bridge

A low twin-track bridge at the end of the Syvash causeway, with ballast, timber sleepers, steel rail pairs, side walkways and alternating lattice catenary masts.

Set the world viewer date to 2016-09-10 for this dated reconstruction. The [map frame](map-frame.json) preserves the independent alignment, control heights and photographic references.

Run `node packages/worldgen/scripts/generate-chongar-bridges.mjs` to regenerate the three source masters. The [bridge recipe](models/bridge-model.mjs) exports the master and four streaming levels. Structural castings and metalwork use shared materials. Detailed hardware, pier spacing and water levels are approximate.
