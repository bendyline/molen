# Kudrinskaya Square Building

This independent Seven Sisters asset follows the mapped H-plan at Kudrinskaya Square. [The map frame](map-frame.json) records the podium outline, paired wings, crown and the terrain datum at the square-facing entrance. Reference pictures inform the arched oak doors, gallery openings, limestone pinnacles, green caps and gilded spire.

The source master and four authored levels reuse limestone, granite, painted metal, copper and wood. Run `node packages/worldgen/scripts/generate-kudrinskaya-square.mjs` to build the source GLB from [the model recipe](models/kudrinskaya-model.mjs).

The steps use sampled viewer grade. The terrain falls toward the northwest behind the building. Door relief, window profiles, masonry ornament and the star are approximate. The model covers the exterior.
