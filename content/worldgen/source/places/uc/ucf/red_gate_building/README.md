# Red Gate Building

This independent Seven Sisters asset follows the mapped footprints on the Garden Ring in Moscow. The long court and residential wings come from [the native map frame](map-frame.json). Reference photographs inform the limestone tiers, granite portico, stone medallion, rooftop loggias, bronze spire and Metro door bank.

The source master and four levels use shared limestone, granite, painted metal, copper and wood. No photograph pixels are included. Run `node packages/worldgen/scripts/generate-red-gate-building.mjs` to generate the source GLB from [the model recipe](models/red-gate-model.mjs).

The central portico uses the sampled Garden Ring grade. The east Metro frontage follows the two mapped entrance points and the slope between them. Ornamental relief, exact glazing, the placement of individual Metro doors, and the crest and star profiles are approximate. The model represents the exterior.
