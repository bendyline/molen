# Kotelnicheskaya Embankment Building

The [model source](models/kotelnicheskaya-model.mjs) reconstructs the hexagonal residential tower, three projecting arms, riverside apartment ranges, arcades, stone crowns and green copper spire. The [site frame](map-frame.json) preserves the native outlines, confluence-facing heading and sampled forecourt grade. Photographs set the crown and facade proportions.

Run `node packages/worldgen/scripts/generate-kotelnicheskaya-embankment.mjs` to regenerate the source GLB. The detailed master and four streaming levels share granite, limestone, painted metal and copper. The model depicts the exterior. Fine sculptures, balconies, door profiles and service elevations are approximate.
