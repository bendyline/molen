# Ministry of Foreign Affairs main building

This independent Seven Sisters asset follows the mapped main building on Smolenskaya-Sennaya Square in Moscow. [The map frame](map-frame.json) preserves the central shaft, stepped wings, rounded rear range, and mapped rooftop ornaments. The historic masonry ribs, bronze portico, crest and silver spire follow ordinary exterior photographs. The separately mapped northern annex stays in the viewer’s base map.

The [model recipe](models/ministry-model.mjs) produces the source master and four streaming levels using shared limestone, granite, painted metal and copper. Run `node packages/worldgen/scripts/generate-foreign-ministry.mjs` to reproduce the source GLB. No photograph pixels are embedded.

The central portico uses the sampled native viewer pavement grade. The relief, window proportions and some low-range details are approximate. The model represents the exterior of the main complex.
