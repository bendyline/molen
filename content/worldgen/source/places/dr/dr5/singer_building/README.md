# Singer Building

Fourteen-story Broadway and Liberty Street base in red brick and bluestone, a slender square shaft with three-part windows and bowed balconies, and a rounded slate mansard with a copper lantern.

Rebuild the exterior master with the Singer Building generator registered in asset-build.json. The runtime exporter generates four detail levels from the same recipe. The building uses shared brick, limestone, ashlar, slate, copper and bronze graphs.

Select 1912-06-01 in the world viewer for the early appearance at Broadway and Liberty Street. The archived floor plan sets the Broadway front and Bourne setbacks. The historical date replaces the One Liberty Plaza footprint and retains the surrounding modern map and terrain.
