# Shaolin Pagoda Forest

Rows of square, hexagonal, octagonal and round brick-and-stone memorials rise across the slopes of the Pagoda Forest. A taller seven-tier pagoda stands inside a low stone enclosure near the approach. Narrow mapped footways thread between the groups. [Reference observations](reference-observations.json)
