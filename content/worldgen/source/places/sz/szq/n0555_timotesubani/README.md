# Timotesubani

![Molen preview](preview.png)

Standing Timotesubani Dormition church and separate mapped brick gateway: cream/pink thin-course brick cross-domed body, stepped nave/transept/aisle gables, tall slit-window blind-arcaded drum with original turquoise geometric accents and gray slab cone/cross. Pale stone gabled porch has a true front passage and twin open side arches, simple original carved pier/rim forms. Separate gateway uses nested pointed brick arch and recessed wood leaves. St Barbara chapel, shop, monastic cells, temporary bell shelter/scaffolding, enclosure beyond gateway and landscaping remain independent host context. No copied frescoes, inscription/sculpture atlas or hidden furnished interior.
