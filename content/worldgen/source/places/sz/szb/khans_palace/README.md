# Khan's Palace (Hansaray)

The Crimean Tatar palace in Bakhchysarai, with its painted North Gate, twin stone minarets and mosque arcade, carved and latticed palace wings, Falcon Tower, fountains and domed tombs.

Seventeen mapped footprints anchor the complex near the Churuk-Su stream. The North Gate follows the mapped raised approach with an open central passage.

Run the Hansaray generator registered in asset-build.json to rebuild the source. The four detail levels use shared lime plaster, ashlar, wood, ceramic roof tile and metal. The historic reference views predate recent restoration and visible detail is interpreted at viewer scale.
